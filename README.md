# ecma-334-conformance-tests

An unofficial conformance suite for C# (ECMA-334).
This suite is not affiliated with or endorsed by Ecma International.

The draft suite lives on the [`draft`](../../tree/draft) branch:

```text
git clone --branch draft https://github.com/lamellaproject/ecma-334-conformance-tests.git
```
